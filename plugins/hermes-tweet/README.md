# Hermes Tweet

Hermes Tweet is a Hermes Agent plugin for X/Twitter exploration, reading, and gated posting through Xquik.

- Source: https://github.com/Xquik-dev/hermes-tweet
- API-backed reads and writes require `XQUIK_API_KEY`.
- Write actions also require `HERMES_TWEET_ENABLE_ACTIONS=true`.
- Local exploration stays available without network credentials.
