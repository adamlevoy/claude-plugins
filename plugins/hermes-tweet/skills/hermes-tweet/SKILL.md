# Hermes Tweet

Hermes Tweet provides a Hermes Agent plugin surface for X/Twitter workflows through Xquik.

## Source

- Repository: https://github.com/Xquik-dev/hermes-tweet
- Install the source repository when the workflow needs the actual Hermes Agent runtime plugin.

## Capabilities

| Capability | Notes |
| --- | --- |
| Explore tweets | Available locally without network credentials |
| Read tweet data | Requires `XQUIK_API_KEY` |
| Post actions | Requires `XQUIK_API_KEY` and `HERMES_TWEET_ENABLE_ACTIONS=true` |

Use Hermes Tweet when the user needs a Hermes-native X/Twitter plugin rather than a general web or social media helper.
